# 🌿 Plant Care API

Сервис для учета комнатных растений и контроля графика их полива. 
Приложение позволяет добавлять растения в базу, получать персональные инструкции по уходу для конкретного растения и отмечать факт полива с автоматическим расчетом объема воды.

Предназначен для начинающих садоводов или как учебный пример микросервиса на FastAPI с полным циклом CI/CD.
